## 🌟 What is INNOVEX OS?
Crises and essential civic services never operate in isolation: an industrial toxic gas leak threatens downwind agricultural canals, hospital trauma beds, and municipal traffic corridors simultaneously. Existing emergency and agronomy tools operate in fragmented, expensive silos.

**INNOVEX OS** fuses 6 critical domains into one synchronized, client-side Edge AI Operating System with zero recurring cloud GPU server costs:

1. **🌾 AgriTech Deep Hub:** In-browser Computer Vision plant leaf disease detection (Early Blight, Powdery Mildew), Subhash Palekar 100% zero-budget organic Jeevamrutha recipe engine, and real-time Karnataka APMC Mandi price comparison (Davangere vs Shimoga vs Hubli).
2. **🏥 HealthTech for Society:** Davangere emergency blood donor geo-radar, Karnataka Big-Four Snakebite Antivenom (ASV 20WBCT) clinical dosage calculator, live 60FPS Lead-II ECG cardiac rhythm monitor, and 110-BPM CPR metronome coach.
3. **🏙️ Smart City & Scam Sentinel:** European Meteorological satellite weather sync (Open-Meteo REST API), emergency traffic green corridor preemption, and heuristic AI scam detection for fraudulent electricity disconnection APKs and fake PM-Kisan subsidy phishing SMS.
4. **🛸 Robotics & Drones:** Leaflet.js GPS waypoint mission planner with 1-tap emergency medical air-drop routing, FLIR thermal infrared night vision toggle, Haversine flight distance math, and Return-to-Launch (RTL).
5. **⚙️ Industrial IoT SCADA:** Real-time HTML5 Canvas FFT vibration harmonics spectrogram, bearing anomaly detection, and toxic ammonia gas leak sensor (>75 ppm) triggering automated safety interlocks.
6. **💡 Open Innovation & AI Copilot:** Interactive trilingual AI Copilot (English, Hindi, and Kannada - ಕನ್ನಡ) answering 50+ domain queries instantly, backed by offline PWA service worker caching.

## 🚀 Quick Start (Local Run)

### Prerequisites
- Node.js (v16+) installed.

### Run Locally
```bash
# Clone the repository
git clone https://github.com/crazy126m-afk/innovex-os.git
cd innovex-os

# Start the zero-dependency server
npm start
# OR double-click run_app.bat on Windows
```
Open **`http://localhost:3000`** in your browser!

## 📱 Mobile App (PWA & APK)
- **Install on Android / iOS:** Open the URL in Chrome/Safari and tap **"Install App"** in the header to run INNOVEX OS as a standalone native app with home screen icon and offline support.
- **Generate APK:** Enter the hosted URL at [pwabuilder.com](https://www.pwabuilder.com) to generate an installable Android `.apk` package in 2 minutes.
